## Purpose

Develop the commissioned small Windows document application to the most complete honestly verified state achievable in the available environment, while preserving a cold-recoverable engineering record in this repository.

## Subject and boundary

The Subject is the target Windows desktop product and all repository-local engineering state required to research, define, design, implement, build, install, verify, document, integrate, and close that target.

Included: problem-space Research, supported DOCX/PDF boundaries, Windows GUI/platform choice, dependency boundary, file/state lifecycle, build, install/uninstall, source implementation, documentation, verification evidence, and closure.

Excluded: use of other user repositories/workspaces as content or architecture sources; third-party product/runtime libraries or document engines; full Microsoft Word/Acrobat parity; PDF editing; background helpers/services/updaters; speculative future features beyond architecture needed to keep v1 evolvable.
