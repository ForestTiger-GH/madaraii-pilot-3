## Current slice and semantic delta

### Session replacement

Current DOCX replacement releases the active PDF before candidate DOCX admission; current PDF replacement releases/clears active state before `PdfSession.OpenAsync` succeeds. Required delta: candidate admission precedes destructive replacement. A failed candidate open leaves the previously established session and its UI state intact except for the ordinary error message/status projection.

### PDF rendering

Current rendering uses one shared `_pdfRendering` flag and no commissioning identity. Required delta: every asynchronous render is bound to the session/page/zoom request that commissioned it. Later session or render requests invalidate stale completions; stale completion may finish internally but may not mutate current UI/status/control state.

### Table columns

Current add/delete changes row cells but not `Table.Columns`. Required delta: the live WPF descriptor count tracks rectangular row-cell width after bounded column mutation.

### Save recovery

Current writer attempts recovery but suppresses recovery failure. Required delta: successful recovery continues to rethrow the original save failure; failed recovery throws a stronger explicit exception stating that target integrity is unknown and retaining both failures as diagnostic causes.
